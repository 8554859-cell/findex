# Захист лабораторної №2

1. Хеш-таблиця використовує хеш для вибору слота; колізії вирішуються пробуванням інших слотів.
2. Якщо a == b, то hash(a) == hash(b). Змінювати поля, від яких залежить хеш ключа, не можна.
3. Списки змінні й не хешуються. Кортеж хешується лише тоді, коли всі його елементи хешовані.
4. Frozen dataclass генерує узгоджений хеш для хешованих полів; власний eq без hash робить клас нехешованим.
5. Slots усуває словник атрибутів екземпляра, але обмежує додавання нових атрибутів.
6. Array зберігає пари без окремих Python-об'єктів і посилань; itemsize визначає розмір числа.
7. Merge працює за O(n+m), set потребує додаткових хеш-таблиць і сортування результату.
8. Pickle може виконати код при десеріалізації, тому завантажуємо лише власні довірені файли.
